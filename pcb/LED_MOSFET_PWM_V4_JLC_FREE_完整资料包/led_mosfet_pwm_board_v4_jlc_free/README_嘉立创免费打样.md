## 接线
- J1.1 PWM → Pico PWM GPIO
- J1.2 GND → Pico GND
- J2.1 LED- → 屏幕背光 LED-
- J2.2 GND → 背光电源/驱动器 GND
- Pico GND、屏幕/背光电源 GND 必须共地。
- LED+ 不经过此板，必须接符合屏幕规格的恒流/限流电源。

## 安全说明
本板只做MOSFET低边PWM开关，不提供LED恒流或限流。R1=100Ω是栅极串联电阻，R2=10kΩ是栅极下拉电阻。
