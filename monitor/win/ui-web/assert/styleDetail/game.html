游戏监控简约

把实时帧率与 CPU、GPU、内存性能放在同一屏，便于定位游戏瓶颈。

FPSCPU / GPU性能分析

指标解释

指标解释判断思路
FPS / AVG / MIN当前、平均和最低帧率。最低帧率明显偏低通常对应卡顿瞬间。
CPU 使用率处理器总体负载。高 CPU 且 GPU 不满，可能受 CPU 或游戏线程限制。
CPU 频率当前处理器运行频率（GHz）。负载高但频率异常低时可检查温度与电源策略。
GPU 使用率显卡核心负载。接近满载且 FPS 未达目标，通常表示 GPU 瓶颈。
显存专用显存已用/总容量。接近上限可能引起资源换入换出与卡顿。
内存系统物理内存占用。持续接近满载可能触发换页。

瓶颈判断需要结合趋势：单次尖峰通常不代表持续限制，CPU 总使用率也可能掩盖单核心满载。
