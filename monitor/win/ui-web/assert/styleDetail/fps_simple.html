指标解释

指标解释
LIVE FPS当前每秒渲染帧数。通常越高越流畅，但还应结合显示器刷新率。
AVG采样窗口内平均 FPS，代表整体性能水平。
MIN采样窗口内最低 FPS，用于发现明显掉帧。
MAX采样窗口内最高 FPS。
JITTER帧率波动程度；数值越大表示帧率越不稳定，体感可能出现卡顿。
SOURCEFPS 数据来源，例如系统采集接口或外部工具。
进程名当前被识别和监控的游戏/图形进程。

高平均 FPS 不代表完全流畅；最低 FPS 和 JITTER 更能暴露瞬时卡顿。NO DATA 表示尚未获取有效帧率。
