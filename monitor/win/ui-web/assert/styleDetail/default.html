经典概览

纵向信息总览，适合快速查看主机资源、网络质量与运行时间。

系统总览趋势曲线

界面布局

顶部显示主机名及联网状态；中部依次显示 CPU、内存、磁盘占用及历史趋势；底部显示上传、下载、Ping、IP、时钟与运行时间。

指标解释

指标含义怎么看
CPU处理器当前使用率与温度。长期接近 100% 表示计算负载较重；温度异常升高应检查散热。
RAM已用内存/总内存及占用率。持续高占用可能引发换页与响应变慢。
DISK逻辑磁盘已用容量/总容量。这是容量占用，不代表硬盘健康程度。
UP / DN实时网络上传与下载速率。单位由设置中的网络速率单位决定。
PING到配置目标的网络往返延迟。数值越小越好；ERR 表示本次探测失败。
UPTIME系统自启动以来的连续运行时间。用于判断近期是否发生重启。

说明

百分比旁的曲线是近期采样趋势，可用于区分瞬时尖峰与持续高负载。
