三盘简洁版

自动优先展示健康等级最高的三块磁盘，减少信息干扰。

3 盘风险优先简洁

选择规则

系统会按磁盘健康等级从高到低选出前三块。因此发生告警的磁盘会优先出现在屏幕上；健康等级相同时保持原磁盘顺序。

指标解释

指标解释
H0–H5健康告警等级，越高风险越大；WARN 表示当前卡片正在强化告警。
容量百分比单盘空间使用比例。
温度磁盘当前传感器温度。
R / W磁盘实时读取和写入速率，旁边曲线展示近期趋势。
CPU / MEM / GPU主机核心资源使用率与趋势。
NET上传、下载与 Ping 网络质量。

如果磁盘数量多于三块，未显示不代表未采集；本样式只展示健康风险最高的三块。
