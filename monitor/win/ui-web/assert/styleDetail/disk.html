磁盘概览

突出总磁盘容量，同时保留 CPU、内存和双向网络趋势。

容量优先网络曲线

界面布局

顶部显示磁盘已用/总容量和占用进度；中间显示 CPU 使用率与温度、内存占用；下方分别绘制上传、下载速率与趋势；页脚显示主机、联网、Ping、时间和运行时长。

指标解释

指标解释
磁盘容量百分比文件系统已使用空间占总空间的比例。容量不足会影响更新、缓存及日志写入。
CPU 温度处理器传感器温度；无传感器数据时显示“--℃”。
内存已用量当前被系统和应用占用的物理内存。
上传/下载趋势一段时间内的网络吞吐变化，用于发现持续传输或突发流量。
在线状态监控端网络连通性判断，不等同于某个应用服务一定可用。

注意

该样式中的 DISK 是总体容量指标，不包含 S.M.A.R.T. 健康告警；需要健康状态请使用多盘样式。
