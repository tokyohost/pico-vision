十五盘 IP 版

十五盘紧凑布局的网络定位版本，顶部优先显示设备 IP。

15 盘IP 地址健康告警

适用场景

适合机柜、多台 NAS 或远程维护场景，可直接从屏幕确认当前主机网络地址。

指标解释

指标解释
IP当前监控主机的网络地址；地址变化通常与 DHCP、网卡切换或网络重连有关。
H0–H5物理磁盘健康等级。H0 正常，等级越高告警越严重；不要与容量百分比混淆。
磁盘百分比单盘已用空间比例。高占用提示清理空间，但不直接说明介质损坏。
DISK OVERALL所有采集磁盘的总体容量摘要。
CPU / MEM / GPU计算、内存和图形处理资源占用。
UP / DN / PING网络上下行吞吐与往返延迟。

H3 以上或持续红色闪烁时，请先确认备份完整，再使用厂商或 S.M.A.R.T. 工具排查。
