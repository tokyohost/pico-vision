像素待机时钟

设备空闲时显示的大号时钟、日期、Wi-Fi 状态和系统状态摘要。

待机时钟Wi-Fi

显示内容

项目解释
时间与日期来自 Monitor 快照的当前时间；无有效时间数据时显示等待提示。
星期当前日期对应的星期信息。
Wi-Fi SSID设备当前连接的无线网络名称。
RSSI（dBm）Wi-Fi 接收信号强度，通常越接近 0 信号越强，例如 -45 dBm 通常强于 -75 dBm。
Wi-Fi 状态灯用于区分已连接与关闭/未连接状态。
SYSTEM LOG待机状态下的设备连接或系统提示摘要。

进入规则

当系统满足设置中的空闲时间后进入待机样式；恢复活动或收到有效显示更新后返回主界面样式。

“WAITTING CONNECT / NO TIME DATA”表示设备尚未收到有效时间快照，不代表屏幕故障。
